🏀 Install the BBL roster bookmark

This bookmark reads the league's rosters from CBS (while you're signed in) and saves them to bbl_rosters.txt in your Downloads. The Best & Worst tables use it to show who owns each player.

1. Show your bookmarks bar: Safari → View → Show Favorites Bar (Chrome: ⌘⇧B).

2. Drag this button onto the bar:

🏀 BBL roster export

Clicking it here does nothing useful: it only works on the CBS league site.

3. Go to your CBS league site, sign in, and click 🏀 BBL roster export on the bar. A box in the top-right shows progress (about 20 seconds), then bbl_rosters.txt lands in Downloads.

4. Run 2 - BBL Tonight. It picks up the newest roster file from Downloads by itself.

Do this again whenever rosters change (after waivers or trades). Old rosters still work; new pickups just show as free agents.

Safari note: if nothing happens when you click the bookmark, turn on Safari → Settings → Advanced → Show features for web developers, then Develop → Allow JavaScript from Smart Search Field. Chrome works without changes.
